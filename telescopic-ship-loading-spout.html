Telescopic Ship Loading Spout

A telescopic spout or similar discharge arrangement, where cargo, control and vessel needs call for it.

Overview

The spout is where the system meets the ship. A telescopic spout, or another suitable discharge arrangement, is considered where the cargo, control approach and vessel interface call for it.

Typical configuration

Mounted at the discharge end of a ship loading conveyor or mobile loader, extending toward the hold as loading progresses.

Where it fits

  • Bulk loading where the hold position changes
  • Operations wanting controlled discharge
  • Sites pairing a spout with a mobile or fixed loader

Key features

Adjustable reach into the hold
Selected to suit cargo and vessel interface
Works with ship loading conveyors and mobile loaders
Control approach discussed per project
Dust-management needs considered where relevant
